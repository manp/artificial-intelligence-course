# درس هوش مصنوعی — ۱۴۰۵-۱

📚 مخزن رسمی و مرجع درس «هوش مصنوعی» — دانشگاه ملی مهارت

این مخزن مرجع دانشجویان این درس است: متن کامل جلسات، تمرین‌ها و منابع. محتوای همین مخزن در ربات درستیار (@darstyar_bot) هم نمایش داده می‌شود؛ هر به‌روزرسانی پس از push در ربات دیده می‌شود.

## 🚀 شروع سریع

1. از جدول **جلسات** پایین، جلسهٔ مورد نظر را باز کنید.
2. هر جلسه یک فایل Markdown کامل است؛ آن را از بالا به پایین بخوانید — جدول‌ها و نمودارها بخشی از متن‌اند، نه ضمیمه.
3. در انتهای هر جلسه بخش **خودآزمایی** است: پنج پرسش برای سنجش فهم. پاسخ‌ها را از متن همان جلسه پیدا کنید.
4. تمرین‌ها از بخش «تمرین‌ها» در ربات ارسال می‌شوند؛ فایل‌های این مخزن فقط متن درس و منابع‌اند.

## 🧭 هر جلسه از چه بخش‌هایی ساخته شده

- **اهداف و پیش‌نیاز** — در ابتدای فایل
- **متن اصلی** — تعریف‌ها، جدول‌ها، نمودار مفهومی و توضیح هر بخش
- **پرسش‌های بحث کلاسی** — برای فکر کردن، بدون پاسخ آماده
- **خودآزمایی** — پنج پرسش برای مرور و سنجش فهم
- **فعالیت کلاسی و تکلیف کوتاه** — تمرین درون‌کلاسی و تکلیف جلسهٔ بعد
- **پرسش‌های باز و منابع** — برای مطالعهٔ بیشتر
